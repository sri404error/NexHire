# AGENTS

## Agent 1: Co-founder Match Agent

### Purpose
Matches students, founders, and entrepreneurs based on skills, interests, startup domains, and goals.

### Inputs
- User profile
- Skills
- Interests
- Startup idea

### Outputs
- Compatibility score
- Matching explanation
- Recommended collaborators

---

## Agent 2: Startup Idea Analyzer

### Purpose
Analyzes a startup idea and provides feedback.

### Outputs
- Strengths
- Weaknesses
- Market potential
- Suggested improvements
