# Product Requirements Document (PRD)

## Project Name
NexHire

## Problem
Students with startup ideas struggle to find co-founders, mentors, and entrepreneurs who can help turn ideas into real startups.

## Solution
NexHire is an AI-powered platform that connects students, founders, entrepreneurs, and mentors using intelligent matching.

## Target Users
- Students
- Startup founders
- Entrepreneurs
- Mentors

Work in Progres
